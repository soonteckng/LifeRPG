# Daily progress presentation

Home displays both sides of the daily goal in minutes. For example, 61 completed minutes toward a 60-minute goal appears as `61 / 60 min`, with the goal-reached heading. Extra seconds remain visible when present. Only the progress bar is capped; credited time and saved records are preserved.

Progress opens with today's recorded effort and finished-session count. Tapping a chart day selects that day's value and opens its existing session details. Week and month totals remain separate, clearly labeled summaries below the chart. In a past period, the initial day is the latest day with recorded sessions, or the last calendar day when the period is empty. The displayed date identifies which day is shown.

Current-period comparisons include only sessions completed by the matching local clock time on the equivalent day of the earlier period, using the account time zone. Earlier days are included in full. The first day receives a factual new-period message. Negative percentages are suppressed while a period is in progress. A completed period may show a neutral comparison when the earlier sample is at least five recorded minutes. Exact completed seconds remain the source for analytics; free sessions are described as finished sessions, never as completed quests.

Automated coverage includes local Monday rollover, same-day clock cutoffs, daylight-saving changes, partial-period messages, historical periods, daily versus aggregate UI values, explicit chart selection, over-goal units, exact seconds, and preserved period-filtered session lists. Installed-phone checks should confirm text fits at increased font size and that a two-minute day does not show the week's total as its primary number.
