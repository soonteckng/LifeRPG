# Routines and connection fixes: focused phone check

Use the newly installed Android preview APK for widgets and cold notification actions. Preserve app data; install over the existing app. An EAS Update cannot add these native changes to an older APK. Use an existing account and two-minute test routines; no new test email account is needed.

1. **Connection transition and haptics.** From Home, turn Wi-Fi and mobile data off, background and return, then reconnect. The outgoing page fades before the incoming page appears. In offline Find your next step, select another category and starting point: each gives feedback when haptics are enabled. Reconnect without tapping Retry; the same saved work remains.
2. **Notification End confirmation.** Start a two-minute session, disconnect, and tap End in app from the ongoing notification. The confirmation appears; Keep session leaves it running, End session stops it. Repeat after clearing the app from recents. A tap on an old notification must never stop a different session. The Session ended card keeps Done after the server reply; Done dismisses both the card and timer presentation.
3. **Progress selection.** Tap a different day's bar: only selection and the list below change. Tap that selected day's bar again: its session list opens. The list below defaults to that day; switch to This week to see all sessions in that week, and back to Selected day. Month mode uses This month.
4. **Save and edit a routine.** In Home → Your routines → Add routine, enter a name, category and two-minute duration. Save; reopen and check all three. Start it once: the timer opens immediately and uses its name/category/duration. Finish it; exactly one completion appears in Progress. A routine is reusable and does not itself create or finish a quest.
5. **Offline routine and recovery.** Disconnect, edit that routine's name/duration, save, then clear the app from recents and reopen offline. The edits remain. Start and finish it offline; reconnect. Routine settings sync, and the session receives its usual single completion/reward through the existing offline pipeline.
6. **Widget, warm and cold.** In Your routines → Manage, tap the widget icon beside a routine and add it. Tap its Start button with the app open, then after clearing recents. Both open the latest saved routine and start once. If another session is already open, its timer opens instead of starting a second session. Edit the routine and check the widget refreshes. Remove it and check the old widget cannot start it.
7. **Reminder and account boundary.** Enable a reminder a few minutes ahead with notification permission granted. Verify one reminder arrives; turn it off or remove the routine and check no extra reminder is scheduled. Sign out: old widgets and routine reminders become inactive. Sign into a different existing account: no previous-account routines appear or start. Returning to the original account restores its saved routines.

Report the case number and what appeared if any case fails. These checks complement automated tests; they do not establish a zero-bug release. Reboot, two-device conflicts and the remaining store-release acceptance cases stay on the release checklist.
